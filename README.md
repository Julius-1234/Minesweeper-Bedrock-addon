# Infinite Minesweeper for Minecraft Bedrock

This is mostly intended for backup, so i won't be very detailed in my explination.
I probably haven't used optimal code (it's kind of slow) so feel free to copy this project and make your own changes.

## how to use

Zip and rename the behavior and resource files for .mcpack.
This add-on is best used in the 'classic flat' world because the y position differs between flat worlds.
If you want to change the game y position go to MinesweeperBehavior/scripts/main.js and change the constant y_pos.
